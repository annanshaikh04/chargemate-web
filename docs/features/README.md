# Feature plans (`docs/features/`)

Before implementing a **non-trivial** feature, add a short plan file here per [`docs/Coding_Guidelines.md`](../Coding_Guidelines.md):

- **High-level goal**
- **Component breakdown** (Server vs Client)
- **Logic and data**
- **Step-by-step implementation plan**

Wait for explicit approval on large changes. For this prototype, many FRs map 1:1 to pages and can reference [`docs/issues/`](../issues/) instead of a separate feature doc unless the feature spans multiple routes.
