# [FR-015] Campaign community features (deck-aligned)

## Labels
`Future`, `enhancement`, `fund`, `feedback`

## User Story
As a backer or visitor, I want **feedback**, **questions**, and a richer **campaign story** experience similar to a crowdfunding platform “create fundraiser” flow, so that the site matches the Everyday Friction MVP deck’s website vision without relying on an external form only.

## Proposed Solution

### Overview
Extend beyond static [`FR-007`](FR-007.md) `/fund` content:

- Dedicated **feedback** path (form stub or third-party embed; store only with backend in later phase).
- **Q&A** section that can grow (start as static FAQ; later moderated submissions).
- Optional **“share your story”** or campaign editor UI **after** CMS/auth exist — align with slide 4 in [`docs/reference/everyday-friction-mvp/page-004.png`](../reference/everyday-friction-mvp/page-004.png).

### Technical Approach
- Phase A: Content-only — expand FAQ and a `mailto:` or Typeform link for feedback.
- Phase B: Requires **FR-011** / API — persist questions and notify team.
- Phase C: Requires **FR-014** — CMS-driven story and media.

## Acceptance Criteria

- [x] Feedback channel documented and reachable from `/fund` or footer (even if external URL) — Phase A: `mailto:hello@example.com` on [`/fund`](../../src/app/fund/page.tsx) and footer **Feedback** link
- [x] Q&A or FAQ reflects deck “questions for audience” themes (features, customization, size) — added FAQ rows on `/fund` (2026-03-30)
- [x] No fake “Start Fundraiser” flow unless backed by real auth and legal review — explicit copy on `/fund`; full editor deferred to Phase C / FR-014

**Phase B/C (still Future):** persisted Q&A, moderated submissions, CMS-driven story (FR-011 / FR-014).
