# [FR-004] Shop — product catalog

## Labels
`MUS`, `enhancement`, `commerce`

## User Story
As a shopper, I want a simple product grid with placeholder SKUs, so that the site feels like a real store.

## Proposed Solution

### Overview
Add `src/app/shop/page.tsx` and `src/lib/products.ts` (or `features/catalog`) exporting static product array used by shop (and later PDP).

### Implementation Flow
1. Define `Product` type and 2–3 mock products with slug, title, price, short description.
2. Render grid of cards linking to `/product/[slug]` (or documented single-PDP shortcut).
3. Match `docs/mockups/shop.html` card layout.

### Technical Approach

```typescript
// lib/products.ts
export type Product = { slug: string; title: string; priceUsd: number; description: string };
export const products: Product[] = [ /* ... */ ];
```

### Key Considerations
- No filters/sort required for MUS unless trivial.
- Images: gray placeholder boxes acceptable.

## Acceptance Criteria

- [x] `/shop` lists all static products in a responsive grid
- [x] Each card shows title, short description, price, and link to PDP
- [x] Data lives in a single module for reuse by FR-005
- [x] Layout matches `docs/mockups/shop.html`
