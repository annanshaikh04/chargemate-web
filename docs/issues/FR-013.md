# [FR-013] Live crowdfunding integration

## Labels
`Future`, `enhancement`, `fundraising`, `integrations`

## User Story
As a backer, I want embedded live campaign data, so that totals stay in sync with a platform.

## Proposed Solution

### Overview
Embed or API-sync with a platform (Kickstarter, Indiegogo, custom) or build backed campaign totals via admin updates—product decision required.

### Key Considerations
- Rate limits, caching, and fallback when API fails.

## Acceptance Criteria

- [ ] Campaign totals on `/fund` reflect live or scheduled-sync data
- [ ] Failure modes degrade gracefully (stale cache message)
