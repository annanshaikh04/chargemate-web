# [FR-011] User accounts and order history

## Labels
`Future`, `enhancement`, `auth`, `users`

## User Story
As a user, I want sign-in and order history, so that I can track purchases.

## Proposed Solution

### Overview
Add authentication (e.g. Auth.js / Clerk / similar) and persist orders per user; protected routes for account and orders.

### Implementation Flow
1. Select auth strategy; configure providers.
2. Database schema for users and orders.
3. Account UI: profile, order list, order detail.

### Key Considerations
- Align with FR-010 order records.
- GDPR/data export if EU users.

## Acceptance Criteria

- [ ] Users can sign in and sign out
- [ ] Order history lists past purchases tied to the user
- [ ] Session security follows provider best practices
