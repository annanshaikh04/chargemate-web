# [FR-010] Real payments and checkout

## Labels
`Future`, `enhancement`, `commerce`, `payments`

## User Story
As a shopper, I want to pay securely, so that I can complete a purchase.

## Proposed Solution

### Overview
Integrate a payment provider (e.g. Stripe Checkout) with server-side session creation, webhook handling for payment confirmation, and clear pre-order vs donation flows if both exist.

### Implementation Flow
1. Choose provider; add env secrets; implement checkout API route.
2. Replace disabled checkout on `/cart` with real flow.
3. Handle success/cancel pages and idempotent webhooks.
