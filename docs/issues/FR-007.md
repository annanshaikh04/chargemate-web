# [FR-007] Fund / campaign page

## Labels
`MUS`, `enhancement`, `fundraising`

## User Story
As a backer, I want a campaign-style page with story, progress, tiers, and FAQ, so that the ask for early support is clear.

## Proposed Solution

### Overview
Static `src/app/fund/page.tsx` replicating `docs/mockups/fund.html`: hero with static progress bar, story section, three tier cards, FAQ accordion or stacked disclosures.

### Implementation Flow
1. Hardcode placeholder raised/goal values with code comment.
2. Tier buttons can be `mailto:` or non-functional with label “prototype”.
3. FAQ: `<details>` elements or simple stacked sections for accessibility.

### Technical Approach

```tsx
const CAMPAIGN = { raised: 52000, goal: 100000 }; // placeholder
```

### Key Considerations
- Do not imply live payment on this page without FR-010.
- Progress bar exposes `aria-label` with percentage for screen readers.

## Acceptance Criteria

- [x] `/fund` includes headline, static progress visualization, and CTA row
- [x] Story section present
- [x] Three tier cards with prices and actions (mailto or disabled)
- [x] FAQ section with at least two items
- [x] Matches `docs/mockups/fund.html` section order and hierarchy
