# [FR-003] Home / landing page

## Labels
`MUS`, `enhancement`, `marketing`

## User Story
As a visitor, I want a clear hero and CTAs to shop and back the project, so that I understand the product quickly.

## Proposed Solution

### Overview
Implement `src/app/page.tsx` to mirror `docs/mockups/home.html`: hero, dual CTA, three value columns, minimal trust strip.

### Implementation Flow
1. Server Component for static marketing content.
2. Map sections 1:1 with mockup order and copy placeholders.
3. Hero image area: placeholder div or `next/image` with static placeholder asset later.

### Technical Approach

```tsx
// app/page.tsx — Server Component
export default function HomePage() {
  return (
    <>
      <section aria-labelledby="hero-heading">...</section>
      <section aria-labelledby="values-heading">...</section>
    </>
  );
}
```

### Key Considerations
- CTAs link to `/shop` and `/fund`.
- Use semantic headings (`h1` once per page).

## Acceptance Criteria

- [x] Home route `/` renders hero with H1 and two primary CTAs
- [x] Three value-prop cards match mockup structure and copy intent
- [x] Trust strip or equivalent minimal line present
- [x] Visual alignment with `docs/mockups/home.html` (spacing, hierarchy)
