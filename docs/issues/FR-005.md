# [FR-005] Product detail page (PDP)

## Labels
`MUS`, `enhancement`, `commerce`

## User Story
As a shopper, I want specs, price, and add-to-cart on a product page, so that I can evaluate the device.

## Proposed Solution

### Overview
Implement `src/app/product/[slug]/page.tsx` (preferred) that loads product by slug from shared static data; fallback `notFound()` for unknown slugs.

### Implementation Flow
1. `generateStaticParams` from product list if using static export pattern; else dynamic segment.
2. Gallery placeholders, spec bullets, price, Add to cart (invokes cart state — coordinate with FR-006).
3. Secondary CTA to `/fund` per mockup.

### Technical Approach

```tsx
// app/product/[slug]/page.tsx
export default function ProductPage({ params }: { params: Promise<{ slug: string }> }) {
  // await params in Next 15
}
```

### Key Considerations
- If Add to cart needs client interactivity, isolate `'use client'` button or use server actions + cookie (localStorage = client).
- Breadcrumb optional; mockup includes simple trail.

## Acceptance Criteria

- [x] PDP resolves product by slug from shared catalog
- [x] Unknown slug returns 404
- [x] Page shows title, price, description, spec list, gallery placeholders
- [x] Add to cart action wired (can noop until FR-006 if documented)
