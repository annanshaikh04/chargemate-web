# [FR-012] Inventory and admin API

## Labels
`Future`, `enhancement`, `backend`, `admin`

## User Story
As an operator, I want backend inventory, so that stock is authoritative.

## Proposed Solution

### Overview
Introduce database-backed SKU inventory; admin-only mutations or internal tools; storefront reads real availability.

### Key Considerations
- Race conditions on checkout (reservations, oversell prevention).

## Acceptance Criteria

- [ ] Stock counts are stored server-side
- [ ] Checkout cannot complete for out-of-stock SKUs
- [ ] Admin or internal path can adjust inventory
