# [FR-006] Shopping cart UI

## Labels
`MUS`, `enhancement`, `commerce`

## User Story
As a shopper, I want a cart with line items and subtotal, so that I can review selections before checkout exists.

## Proposed Solution

### Overview
Client-side cart using React context or lightweight store with `localStorage` persistence; `/cart` page mirrors `docs/mockups/cart.html`. Checkout button disabled with explanatory copy.

### Implementation Flow
1. `CartProvider` in `layout.tsx` or a client wrapper branch (only wrap if needed).
2. `addToCart`, `updateQuantity`, `removeLine` with typed line items `{ productSlug, qty }`.
3. Cart page computes subtotal from static prices + quantities.
4. Stepper UI for quantity (client).

### Technical Approach

```tsx
'use client';
// features/cart/cart-context.tsx
export function CartProvider({ children }: { children: React.ReactNode }) { ... }
```

### Key Considerations
- Hydration: read `localStorage` after mount to avoid mismatch, or use default empty.
- Header cart count should update (small client island in header or context).
