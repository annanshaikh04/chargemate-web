# [FR-014] CMS and marketing automation

## Labels
`Future`, `enhancement`, `marketing`, `cms`

## User Story
As marketing, I want CMS and email capture workflows, so that we can scale content.

## Proposed Solution

### Overview
Integrate headless CMS for pages/blog and email provider for newsletters; GDPR-compliant consent.

## Acceptance Criteria

- [ ] Non-developers can update key marketing copy
- [ ] Email signup flows store consent and integrate with provider
- [ ] Unsubscribe path documented
