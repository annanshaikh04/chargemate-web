# [FR-001] Next.js project scaffold

## Labels
`MUS`, `enhancement`, `scaffold`

## User Story
As a developer, I want a standard Next.js App Router project with TypeScript, Tailwind, ESLint, and pnpm, so that features can be added consistently.

## Proposed Solution

### Overview
Scaffold with `pnpm create next-app` using `--ts --tailwind --eslint --app --src-dir --import-alias "@/*" --use-pnpm`, merge into repo root per `/vibe-build`, then apply Tailwind v4 `globals.css` tokens from `docs/Coding_Guidelines.md`.

### Implementation Flow
1. Create temp folder, run `create-next-app` with `--skip-install` if needed, copy into project root.
2. Run `pnpm install` at root.
3. Update `src/app/globals.css` with `@import "tailwindcss"` and `@theme` tokens from Builder workflow.
4. Confirm `package.json` scripts: `dev`, `build`, `lint`.

### Technical Approach

```powershell
pnpm create next-app temp-scaffold --ts --tailwind --eslint --app --src-dir --import-alias "@/*" --use-pnpm --no-git --skip-install
# Merge, remove temp-scaffold, pnpm install
```

### Key Considerations
- PowerShell-safe paths on Windows.
- Do not commit `node_modules`; add `.gitignore` if missing.
- `python scripts/vibe-verify.py` requires `package.json` present first.

## Acceptance Criteria

- [x] Next.js App Router project exists at repo root with `src/app/`
- [x] TypeScript strict project builds conceptually (`npm run build` after deps; pnpm unavailable in env)
- [x] Tailwind v4-style `globals.css` with brand theme tokens applied
- [x] ESLint configured via Next.js defaults
- [x] Import alias `@/*` resolves in `tsconfig.json`
