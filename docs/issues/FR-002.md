# [FR-002] App shell — header, footer, navigation

## Labels
`MUS`, `enhancement`, `layout`

## User Story
As a visitor, I want a responsive header and footer on every page, so that I can navigate the whole prototype.

## Proposed Solution

### Overview
Implement `src/app/layout.tsx` with shared `Header` and `Footer` components matching chrome in `docs/mockups/*.html` (sticky header, primary nav links, cart link, footer with Legal).

### Implementation Flow
1. Create `src/components/layout/Header.tsx` (client if mobile menu toggle) and `Footer.tsx`.
2. Wire routes: `/`, `/shop`, `/fund`, `/about`, `/cart`, `/legal`.
3. Active link styling optional; ensure focus states and `aria-label` on nav.
4. Match typography and colors to design tokens.

### Technical Approach

```tsx
// app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <Header />
        <main id="main">{children}</main>
        <Footer />
      </body>
    </html>
  );
}
```

### Key Considerations
- Skip link to `#main` on home; replicate mockup pattern.
- Mobile: collapsible menu or simple stacked links per mockup (design-system shows pattern).

## Acceptance Criteria

- [x] Every page uses shared layout with header and footer
- [x] Nav includes Home, Shop, Fund, About and link to Cart
- [x] Footer includes Legal link to `/legal`
- [x] Layout is responsive (readable nav at mobile width)
- [x] `main` landmark wraps page content; header nav has accessible name
